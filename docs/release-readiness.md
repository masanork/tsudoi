## PR2 後の名簿・受付改善

司令塔が仕様と受入テスト、API と画面の実装者が開発、独立レビュワーが権限・監査・同時実行を確認する分担で進めた。

- 名簿から氏名・標準の所属・カスタム回答・会場を編集する。`owner` / `admin` のセッションに限定し、メール・チケット状態は変更しない。リビジョンが古ければ409で拒否し、変更前後を回答も含めて同じ D1 batch で監査する。
- 受付済みの会場変更は409で拒否する。理由付き受付取消で `issued` に戻した後に変更し、過去の受付履歴は保持する。氏名・所属・回答の編集は受付済みでも可能。
- CSV の列対応、プレビュー、重複候補の確認、行ごとの確定判断を用意した。UTF-8 CSV の BOM、CRLF、引用符内のカンマ・改行・引用符を扱い、列数不一致や閉じていない引用符は拒否する。1回の取込は1MB・100行・100列まで（PR4で107列に拡張）、セルの文字数合計は40万まで。一時保存するプレビューも1MB以下に制限する。
- CSV の必須・型・会場をプレビューと確定で検証する。既存候補は既定で除外し、明示的に新規登録も選べる。候補にない新しい重複や定員超過で全体をロールバックし、プレビューの再利用による二重登録を防ぐ。プレビューは操作者・組織・イベントに限定し15分有効、成功時には一時保存した参加者情報を消去する。期限切れ・確定済みの行は次のプレビュー・確定操作時に削除する。期限切れ情報の定時削除は実装していない。
- CSV 取込は既存参加者を更新せず、`admin` 経路で `issued` チケットを作成する。取込自体はメールを送らない。メールがある参加者には管理者が「チケットを送信」から個別に送信でき、メールのない参加者は名簿から本人確認して受付する。
- 受付結果を大きく表示し、担当者を表示名で示す。カメラは連続読取し、同じ QR が映り続けても繰り返し送信しない。検索からの受付には氏名・所属・会場・回答の確認画面を挟む。スタッフ・viewer は権限に応じた画面を使う。

### PR3 後の CSV レビュー修正

PR3 のマージ後に届いた自動レビュー4件を、API実装・画面と統合テスト・独立レビューに分けて修正した。

- 行・回答ごとの SQL を、JSON を使う固定10文の D1 batch に置き換えた。100名・90項目・9,000回答の取込では、認証から確定まで15文、1文の bind は最大7個だった。[D1 の上限](https://developers.cloudflare.com/d1/platform/limits/)は無料枠で1呼出し50文、1文100 bind のため、この検証ケースは上限内に収まる。SQL と bind のサイズも計測した。
- 会場はイベント内で一意の名前または ID を受け付ける。曖昧な名前、他イベントの ID、不正な数値・非有限値はプレビューで拒否する。同名会場がある場合は出力にも ID を使い、同じイベントへの再取込を可能にする。
- CSV 出力に標準の所属・会場名を含める。複数選択は JSON 配列で出力し、区切り文字を含む選択肢を保持する。負の有限数値は再取込できる形で出力し、数式に見える文字列の保護を続ける。
- 標準見出しや別のカスタム項目と衝突する見出しは `answer:<field_key>` にして一意にする。画面もこの見出しを自動対応する。
- イベントの項目読込が終わるまで CSV 選択を無効にし、読込前の自動対応で回答が欠落する問題を防ぐ。
- 取込列数の上限を107列に拡張し、100カスタム回答列と7標準列を含むCSVも受け付ける。100行・1MBファイル・40万セル文字数・1MBプレビューの各上限は維持する。

CSV出力の参加者数・項目数は取込上限より大きくなり得る。100行・107列・1MBを超えるCSVは、再取込前に行を分割し、不要な列を除外する。フォーム項目の作成数を制限する変更は含めない。

定員超過・同時確定・プレビュー後の会場削除や項目変更では、参加者・チケット・回答・監査をまとめてロールバックする。CSV の出力を別イベントへ再取込し、所属・会場・改行を含む回答・標準見出しと同名のカスタム項目をブラウザで検証する。追加マイグレーションはない。本番では PR3 の `0004` を適用してから配置する。

最終検証は TypeScript / Svelte エラー0・警告0、通常テスト12件、Worker / D1 テスト53件、Chromium テスト5件が成功。本番設定の deploy dry-run も成功し、アップロードはしていない。上記の大容量取込では、1文の SQL は最大1,135 bytes、単一の bind 文字列は828,701 bytesだった。独立レビューで見つかった見出し衝突も修正し、出力・再取込の回帰テストを追加した。PR4の自動レビュー追加2件も修正し、同名会場のIDによる再取込と、100名・100回答・107列のCSV出力から再取込まで（最終20,000回答）を検証した。
